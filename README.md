# 天上掉下一幅画

把一次无人机飞行变成一件能转着看的 3D 轨迹雕塑、一张高清艺术海报和一枚飞行勋章——纯前端、零后端、作品只存本机浏览器。

**在线演示**：<https://sky-painting-m33wci77q34.qoder.zone>

## 核心功能

1. **轨迹来源三选一**：内置示例航迹、导入自己的飞行日志 CSV、或直接在 300m 空域里手绘一笔。
2. **3D 轨迹雕塑**：变径管线（粗处慢、细处快）、低空偏青→高空偏暖金的高度渐变、转弯发光标记；可拖动旋转、滚轮缩放、静置自转。
3. **自动命名与飞行勋章**：按飞行特征纯规则颁发勋章与颁奖词，画名候选可换批或手改，零外部 AI 接口。
4. **高清海报导出**：晴空 / 黄昏 / 夜航三模板，1200×1600 竖版，预览与下载同源同版，一键 PNG。
5. **本地画廊与拼墙**：作品以轻量 JSON 存本机，可回看、重下载、删除；多选 2–9 张拼成 1600×1600 作品墙。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：`npm run build`（产物在 `dist/`）。

## 技术栈

Vite + React + Three.js + Tailwind CSS v4。纯前端单页，无后端、无数据库、无密钥 API；系统字体，不加载外部字体资源。
